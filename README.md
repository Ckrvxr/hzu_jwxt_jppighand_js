# 惠州学院教务系统一键教评助手 (HZU JWXT JPPighand)

惠州学院教务系统一键教评 Tampermonkey 油猴脚本。自动为评分面板添加"一键评价"按钮，可批量评价所有课程，支持选择评分等级（最高分/次高分随机分布），简化繁琐的教评流程。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 打开 `hzu_jwxt_jppighand.js` 原始文件，或复制代码到新建脚本中保存
3. 访问 `jwxt.hzu.edu.cn` 教务系统教评页面即可使用

## 使用

进入教评页面 → 点击"评价"按钮 → 在弹出面板中选择期望评分等级 → 点击"一键评价"完成。
